# ABC 123! — architecture

## Shape
A static PWA: no framework, no build step, GitHub Pages. Offline via `sw.js`.
Everything the child sees is **data, config or a module**. The engine (`abc/core/`) names no subject, language,
profile or word. Adding a word, a language, a module or an age profile never edits `abc/core/`, `abc.html` or `sw.js`.

```
abc.html                    markup of the shell + views, all CSS (tokens → components); loads abc/manifest.js, then its scripts
abc/manifest.js             GENERATED by `node tools/check.js --fix`: script order, offline file list, version hash
abc/config.js               languages, modules, sections (tabs), age profiles, base language
abc/concepts.js             one line per concept: stable ASCII id + picture, e.g. C('cow', '🐄')
abc/art.js                  pictures that are content: ART(id, svg) — the age-profile bikes
abc/lang/<code>/grammar.js  LANG(): name, flag, bcp47, dir, letters, forms() + optional hooks (see LANG in registry.js)
abc/lang/<code>/strings.js  STRINGS(): UI text (tabs, praise, plural templates, aria labels, profile names …)
abc/lang/<code>/words.js    the word for each concept + explicit grammatical forms
abc/lang/<code>/info.js     "What is it?" cards, keyed by concept id (optional)
abc/modules/<id>/module.js  MODULE(): builds its own items per language; declares tiles (learn view + game), needs, checks
abc/modules/<id>/lang/<code>.js  MSTRINGS(): the module's tile labels and spoken questions
abc/core/registry.js        global ABC + the registration functions — and every contract (LANG, MODULE, TILE, VIEW, GAME)
abc/core/i18n.js            templates + Intl (PluralRules, Segmenter, ListFormat, Collator), letter units, upper()
abc/core/content.js         ITEM fields; word items; the alphabet of a language (units, colours, letter names); ink palette
abc/core/tiles.js           the one rule set "what a tile shows and when" — used by the app AND tools/check.js
abc/core/services.js        $, storage, sound effects, speech (local voices first), confetti
abc/core/views/*.js         VIEW(): card, read, count, play
abc/core/games/*.js         GAME(): find, howmany
abc/core/shell.js           hubs, tabs, flags, profiles, navigation, language switch, index, search, info cards, input, APP
sw.js                       precaches MANIFEST.files under cache 'toddler-<version>'; network-first, cache when offline
tools/check.js              content + config checks, manifest generator (CI)
tools/fast.js               layout check, ~2 s, no server: every screen × 7 sizes (CI)
tools/smoke.js              browser test: every language, every game, speech, offline (CI)
```

## Key rules
- **Ids, not words.** Words, info cards and saved progress are keyed by concept id (`cow`), never by text or emoji.
- **Explicit forms.** Each language writes its forms (RO `def`, `pl`, `plDef`, `g`; DE `g`, `pl`, `mass`; EN `art`, `pl`, `mass`, `plOnly`).
  Grammar code only assembles them; school rules are checks (`checkForms`, `checkWord`), not generators.
- **Base language.** Missing UI strings fall back to `config.baseLanguage` (en); `check.js` reports every missing key.
- **Modules don't share data.** `build(code)` returns the module's own namespace; its tiles read only that.
  Language data a module reads is declared in `needs` (e.g. `numbers`, `sayLetter`) and checked for every language.
- **A tile is never shown broken** (`abc/core/tiles.js`): a learn tile needs its label + items; its game needs its label
  and enough playable items at its first and its hardest round. Otherwise it is hidden in that language.
- **Age profiles** (config, ascending): little 2–4 · explorer 4–7 · scientist 7–12, shown as bikes in the top bar on every
  hub; anyone may switch. A tile's start age (`tile.ages` or `module.ages`) picks its profile (start < upper: 4 → explorer);
  the tile shows from that profile upwards (higher profiles add, never remove) and wears that profile's badge
  (left → right in profile order). A profile with `soon: false` (Little) never shows "coming soon" tiles.
- **Speech** uses only a voice of the current language (local first, `LANG.voices` preferred). No voice → 🔇 on the flag.
- **Globals.** Content files only call the registry. Views and games use `APP`, `CONTENT`, `I18N`, `esc` and the services
  (`$`, `speak`, `sfx`, `store`, `confetti` …). The shell keeps its state in script-scope variables; the tests drive it directly.

## UI rules
- **One class and one base style per component** (`.pill`, `.rbtn`, `.seg`, `.group`, `.sheet`, `.ht` tile, `.label`, `.dot`, `.scroll`).
  No per-screen or per-section overrides; a variant is a modifier class (`.primary`, `.small`, `.accent`).
- **Tokens.** Colours, radii, type, spacing, sizes and z-index live in `:root`. The three breakpoints
  (width ≤ 440, width ≤ 350, height ≤ 700) only reassign tokens.
- **One selected look**: `.on` (ring + raised card) for everything that can be picked or is being read aloud.
- **One visibility mechanism**: the `hidden` attribute, set by the shell (`[hidden]` wins over any display).
- **One content column**: `--col` / `--gut` place the top bar, every screen, the ‹ › arrows, the sheets and the tab bar.
  Controls fixed above the tab bar carry `data-low`; a screen too tall for the space calls `APP.fit(el, compactClass)`
  (compact first, then scale to fit) instead of its own sizing code.

## Recipes
**Add a word** — `abc/concepts.js`: `C('wolf', '🐺');` then in each `abc/lang/<code>/words.js`:
```js
w('wolf', { w: 'lup', def: 'lupul', pl: 'lupi', g: 'm', plDef: 'lupii' }); // '/' marks syllables (all languages)
```
**Add a "What is it?" card** — `abc/lang/<code>/info.js`: `i('wolf', { title: 'Lupul', lines: [['🐺', '…'], ['🌲', '…']] });`

**Add a language** — create `abc/lang/<code>/{grammar,strings,words,info}.js` (copy `en`), add the code to
`config.languages`, add `abc/modules/<id>/lang/<code>.js` for each module, run `node tools/check.js --fix`.
The flag, tabs and offline cache follow automatically. Tiles without text in that language stay hidden.

**Add a module** — `abc/modules/<id>/module.js`:
```js
MODULE('shapes', { section: 'disc', ages: [2, 6],
  build(code) { return { shapes: [/* items: {id, label, name, say, big, …} — see ITEM in content.js */] }; },
  tiles: [{ id: 'shapes', icon: '🔺', view: 'card', items: S => S.shapes, index: true, game: { type: 'find' } }] });
```
plus `lang/<code>.js` with `MSTRINGS('shapes', code, { tiles: { shapes: ['Forme', 'Găsește forma'] }, games: { shapes: 'Unde e {name}?' } })`,
add `'shapes'` to `config.modules`, run `node tools/check.js --fix`. The Play tile is created from `game` (1 learn ↔ 1 game).

**Add an age profile** — `config.profiles.<id> = { ages: [from, to] }` (ascending order), `ART('<id>', svg)` in `abc/art.js`,
`profile.<id>` in each `strings.js`.

**Add a view or a game type** — `abc/core/views/<id>.js` with `VIEW(id, {el, show, announce, …})` (contract in registry.js;
its element is created in the stage if `abc.html` has none — add markup and CSS there only for fixed controls) or
`abc/core/games/<id>.js` with `GAME(id, {needs, pool, prompt})`; run `node tools/check.js --fix`.

## Checks
```
node tools/check.js --fix        # after every change: content + config checks, rewrites abc/manifest.js
node tools/fast.js               # ~2 s, no server: every screen × 7 sizes (320×480 → 1920×1080) — after any CSS/markup edit
node tools/smoke.js [url] [WxH]  # full suite (minutes), repo's parent folder served on :8765 — before a push
```
CI (`.github/workflows/check.yml`) runs check, fast and smoke (360×640 and 320×568) on every PR and on pushes to main.
