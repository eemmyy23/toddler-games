# ABC 123! — architecture (v1.0.0)

## Shape
A static PWA: no framework, no build step, GitHub Pages. Offline via `sw.js`.
Everything the child sees is **data or a module**. The engine (`abc/core/`) has no per-subject, per-language or per-word code.
Adding a word, a language or a subject never edits `abc.html`, `sw.js` or `abc/core/`.

```
abc.html                    markup + CSS; loads abc/manifest.js, then the scripts it lists (in order)
abc/manifest.js             GENERATED by `node tools/check.js --fix`: script order, offline file list, version hash
abc/config.js               languages, modules, sections (tabs), age profiles, base language
abc/concepts.js             one line per concept: stable ASCII id + picture, e.g. C('cow', '🐄')
abc/lang/<code>/grammar.js  LANG(): name, flag, bcp47, dir, letters, number words, how a letter is said, forms()
abc/lang/<code>/strings.js  STRINGS(): UI text (tabs, praise, plural templates, …)
abc/lang/<code>/words.js    the word for each concept + explicit grammatical forms
abc/lang/<code>/info.js     "What is it?" cards, keyed by concept id (optional)
abc/modules/<id>/module.js  MODULE(): builds items from the language data; declares tiles (learn view + game)
abc/modules/<id>/lang/<code>.js  MSTRINGS(): the module's tile labels and spoken questions
abc/core/registry.js        global ABC + the registration functions above
abc/core/i18n.js            templates + Intl (PluralRules, Segmenter, ListFormat, Collator), letter units, upper()
abc/core/content.js         shared helpers: word items, example words for a letter, colours
abc/core/services.js        storage, sound effects, speech (local voices first), confetti
abc/core/views/*.js         VIEW(): card, read, count, play
abc/core/games/*.js         GAME(): find, howmany
abc/core/shell.js           hubs, tabs, flags, navigation, language switch, index, info cards, profiles, input
sw.js                       precaches MANIFEST.files under cache 'toddler-<version>'; network-first, cache offline
tools/check.js              content checks + manifest generator (CI)
tools/smoke.js              browser test: every language, every game, layout, offline (CI)
```

## Key rules
- **Ids, not words.** Words, info cards and saved progress are keyed by concept id (`cow`), never by text or emoji.
  Progress (stars, positions, misses) survives a language switch and content edits.
- **Explicit forms.** Each language writes its forms (RO `def`, `pl`, `plDef`, `g`; DE `g`, `pl`; EN `pl`, `mass`, `plOnly`).
  Grammar code only assembles them; school rules are checks in `check.js`, not generators.
- **Base language.** Missing strings fall back to `config.baseLanguage` (en). `check.js` reports every missing key.
- **A tile is never shown broken.** A learn tile needs its label + items; its game needs its label + ≥ 2 playable items.
  Otherwise it is hidden in that language (e.g. letter groups exist only in Romanian).
- **Age profiles.** little 2–4 · explorer 4–7 · scientist 7–12, picked with the three bikes in the top bar (balance bike,
  training wheels, mountain bike), visible on every hub. No lock: a curious child may switch. Cumulative: a module shows
  if `module.ages[0]` ≤ the profile's upper age, so a higher profile adds topics and never removes one. Little hides "coming soon".
- **Speech** uses only a voice of the current language (local first). No voice → 🔇 on the flag, never a foreign voice.

## Recipes
**Add a word** — `abc/concepts.js`: `C('fox', '🦊');` then in each `abc/lang/<code>/words.js`:
```js
w('fox', { w: 'vul/pe', def: 'vulpea', pl: 'vulpi', g: 'f', plDef: 'vulpile' }); // ro: '/' marks syllables
```
**Add a "What is it?" card** — `abc/lang/<code>/info.js`: `i('fox', { title: 'Vulpea', lines: ['…', '…'] });`

**Add a language** — create `abc/lang/<code>/{grammar,strings,words,info}.js` (copy `en`), add the code to
`config.languages`, add `abc/modules/<id>/lang/<code>.js` for each module, run `node tools/check.js --fix`.
The flag, tabs and offline cache follow automatically. Tiles without text in that language stay hidden.

**Add a module** — `abc/modules/<id>/module.js`:
```js
MODULE('shapes', { section: 'disc', ages: [2, 6],
  build(code) { return { shapes: [/* items: {id, name, say, big, bubble, prompt, …} */] }; },
  tiles: [{ id: 'shapes', icon: '🔺', view: 'card', items: S => S.shapes, game: { type: 'find' } }] });
```
plus `lang/<code>.js` with `MSTRINGS('shapes', code, { tiles: { shapes: ['Forme', 'Găsește forma'] }, games: { shapes: 'Unde e {name}?' } })`,
add `'shapes'` to `config.modules`, run `node tools/check.js --fix`. The Play tile is created from `game` (1 learn ↔ 1 game).
Tile flags: `index: true` → ⊞ grid of all items (A–Z sections + side letter bar when the view sets `indexSort`);
`search: true` → items are found by the universal search (🔍 on every hub and in the index), matched in every language.

**Add a view or a game type** — `abc/core/views/<id>.js` with `VIEW(id, {el, show, step, …})` or
`abc/core/games/<id>.js` with `GAME(id, {needs, pool, prompt})`; the manifest picks it up.

## Checks
```
node tools/check.js --fix      # after every change: checks content, rewrites abc/manifest.js
node tools/smoke.js [url] [WxH]  # needs the repo's parent folder served on :8765
```
CI runs both on every PR and on main (`.github/workflows/check.yml`).
